Boarding at Majestic

Follow Purple Line signs towards Whitefield (Kadugodi). If you arrived on the Green Line, the transfer inside Majestic happens before this guide starts. The stop count below describes the Purple Line ride only. Keep any time needed for the approach to the station, security and transfer separate when arranging a pickup at the destination.

Returning from the eastern corridor

For the return from Whitefield (Kadugodi), take the Purple Line towards Challaghatta and leave at Majestic. The same station sequence runs in reverse. If you change the return origin to a nearer station, use the planner again so the stop count matches the new journey.

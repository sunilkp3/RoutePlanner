How the route planner works

This independent site helps you understand station sequences and line changes before a journey. It works from a local station network in your browser. BMRCL operates the metro and is the authority for tickets and service information.

Coverage and data provenance

The stored network contains the Purple Line between Challaghatta and Whitefield (Kadugodi), the Green Line between Madavara and Silk Institute, and the Yellow Line between Rashtreeya Vidyalaya Road and Delta electronics Bommasandra. The station names, order and approximate coordinates are maintained in this website's source. This is a defined planning dataset, not a live or complete inventory of every current and future Bengaluru Metro service.

The corridor endpoints, station order and interchange junctions were cross-checked on 20 October 2026 against the BMRCL Phase 1, 2, 2A and 2B map. That map also includes planned corridors and does not establish which services are operating today. The Government of India announcement dated 9 August 2025 describes the RV Road–Bommasandra Yellow Line as a 16-station corridor. These are reference documents, not an automatic data feed. Approximate station coordinates are retained from this site's local dataset and are not surveyed entrances. Network changes require a separate update.

How a route is calculated

Adjacent stations on each represented line form connections. The planner finds a path with the fewest station-to-station segments. It groups consecutive connections on the same line into a leg, and inserts a transfer only where the line changes. A journey through Majestic without a line change adds no transfer. Train directions come from the ordered stations on the line used for that leg, including a separate order for each line at an interchange.

“Stops” means stations reached after boarding. A 7-stop journey has 8 stations in its complete list because that list includes the origin. Selecting the same station twice produces an explanation that no train journey is needed, rather than an empty result.

Fare, timing and platform information

The site does not have a verified current station-pair fare table, live train positions or station departure feed. It therefore provides no numeric fare, platform number or predicted departure. Train frequencies alone cannot identify the next train at an arbitrary station. Use BMRCL ticketing for the fare and station displays for boarding and departures. No travel duration formula is presented as an operator timetable.

Nearby-station lookup

You can request a single device-location lookup. The calculation compares approximate station coordinates using straight-line distance, entirely in the page. It does not find entrances, crossings, accessible paths or the best first-mile route. A result more than 15 km away is not automatically assigned. Poor device accuracy can select the wrong nearby station; check the result before planning.

Guides and corrections

Route-guide stop lists and outward/return instructions are generated from the same network as the planner, so their line changes remain consistent. Editorial sections explain the choices for each journey. To report a correction, include both station names, the incorrect step and an official source when available. We do not mark a content revision as a live service verification.
